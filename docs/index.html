사용법 · 테스트 가이드

로그인 없이 누구나 사용할 수 있습니다. 아래 순서대로 따라 하면 각 메뉴를 바로 테스트할 수 있어요.

🚀 3분 빠른 시작

  1. 서식 탐색에서 검색어(예: 임대차)를 입력하거나 대분류를 골라 목록에서 서식을 클릭합니다.
  2. 오른쪽 「기본 정보 입력」에 갑·을·금액·기간을 입력하고 「초안 생성」(규칙 기반 — 어디서든 동작) 또는 「✨ AI 초안 생성」(사내망)을 누릅니다.
  3. 저장 형식(DOCX·HWPX·TXT)을 고르고 「문서 파일 저장」 — 처음 1회만 「저장 폴더 연결」로 폴더를 지정하면 이후 그 폴더에 바로 저장됩니다.
  4. AI 기능은 상단 탭의 「AI 계약서 검토」·「AI 바로 생성」에서 사용합니다. 사내망 전용

저장한 파일이 안 보인다하단 상태줄에서 저장 폴더 연결 여부를 확인하세요. 미연결 시 브라우저 다운로드로 저장됩니다.
「저장 폴더 연결」이 안 눌린다Chrome·Edge 등 File System Access API 지원 브라우저가 필요합니다. Safari·모바일은 다운로드로 대체됩니다.
바뀐 게 없는 것 같다헤더의 버전 배지를 확인하고 강력 새로고침(Cmd+Shift+R / Ctrl+F5)을 하세요.
즐겨찾기·이력이 사라졌다브라우저·프로필별로 따로 저장됩니다. 시크릿 모드에서는 저장되지 않습니다.
